# Public agent handoff

This directory exposes only this README and [PUBLIC.md](PUBLIC.md), a
repository-specific, public-safe orientation for contributors and agents.

Private local `STATE.md`, `MEMORY.md`, `JOURNAL.md`, references and social records
are intentionally ignored. Do not force-add them or export sibling contexts.
Credentials never belong in either public or private context files.

Use the [documentation hub](../docs/README.md), [TODO index](../TODO/00_INDEX.todo)
and [development ledger](../TODO/04_DEVELOPMENT_LEDGER.todo) as the public sources
of current contracts and dated evidence. Public handoff notes are not execution,
human approval or publication receipts.
