# Before opening the DS

This is the separate BowserBOY DS book: a development journey followed by an
engineering explanation of the Nintendo DS experience. It does not import
the original console's hardware, emulator or historical teaching chapters.
The existing book, *Building a Little Escape*, remains an independent,
preserved publication.

The central problem is joining an existing native emulator to an expressive,
recoverable physical-feeling browser appliance. Two screens, a hinged body,
precise touch, a clipped stylus and a local cartridge are not separate
decorations. Their coordinate systems, clocks and failure states must agree.

## What this edition means

The implementation cutoff is
`61845372142b41992916f3732ea102cc0f4c8edf`, November 7, 2026.
The new manuscript describes that source; its own publication can occur
later. Historical workstreams retain their original states and failures.
A later supported-console designation does not retroactively turn every
earlier prototype into a fully qualified release.

DS direct boot uses EmulatorJS 4.2.3 and DeSmuME. Original Nintendo DS
cartridges are in scope; DSi-enhanced/DSi-only files are rejected. No commercial
ROM, BIOS or firmware is included. Local cartridge selection does not upload
the ROM to a gameplay server, but first runtime startup needs CDN access.
No universal game-compatibility, multiplayer, physical-phone performance or
permanent browser-storage guarantee is made.

The cutoff's hosted suite declared 119 cases: 98 passed and 21 were explicitly
parked/skipped. Zero failures in that run does not mean 119 passes or repaired
coverage. Some original workstreams remain open for broader qualification or
owner review. Chapter 11 explains how those facts coexist with a supported,
published console.

## Choose a route

Read chapters 01-02, then 11-12, for the causal journey and its evidence.
Read chapters 03-07 to follow a cartridge through the runtime, display, input
and save boundaries. Chapters 08-10 explain the physical scene, algorithms and
design choices. Chapter 13 is a practical change-and-recovery field guide.

Diagrams explain ownership or ordering; captions state what their arrows
mean. Worked examples and changed-condition retries teach the mechanism.
Questions have explained answers, not implied records of a reader's progress.
The source register binds claims to public repository files and symbols.
This is not an exhaustive source atlas or a Nintendo DS CPU textbook.

## Pictures and evidence

The logo is existing supplied DS artwork, not newly generated cover art.
Scene figures use existing public showcase GIFs; print embeds only frame zero.
The HTML reading edition uses the same labeled stills. The animated originals
remain in the repository. Their game displays replay recorded native opening
footage during real scene interactions; these are not live game-input tests.
No raw recording or private capture path is part of this book.

Code inspection, automated checks, visual inspection, actual public delivery
and human approval are different evidence layers. Rendering this edition
does not rerun historical gameplay checks or establish aesthetic approval.
