A QUICK START

Your games. Your save points.

1. Insert a cartridge

Choose an uncompressed .gba file you have the right to use. It is read locally, not uploaded. No ROM or BIOS collection is supplied. The original Pixel Lab demo is included to try the player.

2. Play

Click the game for keyboard focus. Use arrows, X/Z for A/B, A/S for L/R, Enter for Start and Shift for Select. On phones, use the emulator's on-screen controls. The emulator menu offers control remapping, audio and display settings.

3. Keep your place

Auto-save records one rolling checkpoint every 15 seconds, including the game's battery save when present. Selecting the same ROM later resumes the newest stored checkpoint, even if its file was renamed. Save checkpoint keeps a separate manual slot; Restore rolls back to it. Save manually before closing: abrupt shutdowns can lose progress since the last completed write.

4. Take a backup

Export captures the current session to a .bba-save file. Load the matching ROM before importing. Imports replace the current session and quick-save slot. Backups are specific to this ROM's exact bytes and EmulatorJS 4.2.3 / mGBA, not interchangeable with other emulators' .sav files.

Progress belongs to this browser and website origin. Private browsing, storage eviction or clearing site data can remove it. Different ports, devices or a different website origin do not share saves. Export regularly. ROM files are not retained; reselect yours to continue.

This is an independent prototype, not affiliated with Nintendo. Internet is required for the pinned third-party emulator runtime. That CDN receives normal network metadata and executes code in the player; there is no offline guarantee or cloud synchronization.
