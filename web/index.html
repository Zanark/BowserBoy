A QUICK START

Your games. Your save points.

Insert a cartridge

Open the cartridge slot or press Escape. Choose an uncompressed .gba file you have the right to use, or try the original Pixel Lab demo. Files are read locally, not uploaded. No commercial ROM or BIOS collection is supplied.

A handheld you can hold

Click the 3D handheld on the table to pick it up. Inspect lets you drag it around to see its sides and battery cover. Use arrows to rotate, +/minus to zoom, or Home to reset while inspecting. Back to play returns it to a playable angle; Put down returns it to the table. The other cartridges are original decorative props, not supplied games.

Play, the familiar way

Use the physical buttons, or click the 3D display for keyboard focus. Defaults: arrows to move, Z = A, X = B, A/S = L/R, Enter = Start, left Shift = Select. Hold Space for 2x; release for 1x. Remap keys in Cartridges; assigning Space to a GBA button gives that binding priority over fast-forward. CRT Geom is the default screen shader; choose any of the nine native CRT presets or Unfiltered there if preferred. No buttons cover the LCD. Keyboard and mouse/touch controls are active in play view; the game keeps running on the table and while inspecting until you pause it. Connected gamepads retain their native runtime mappings.

Power and pause

The physical switch powers the emulator off and stores available in-game save data. Turn it back on to boot the loaded ROM from the beginning, then use the game's own Continue/Load menu. The dock's power-cycle icon safely switches off, then on; it is not checkpoint restore. Power on never restores an instant checkpoint. Pause game in Cartridges keeps the current session instead.

Quick controls

The icon dock offers whole-player fullscreen and a separate screen-only fullscreen view, control remapping, autosave, checkpoint save/load and slot selection. Screen-only mode displays the current live LCD without the handheld or room; keyboard controls keep working and Escape returns to the desk without restarting the game. Hover or focus an icon for its label. The fast-forward icon offers 1x, 2x, 3x and 4x native emulation speeds; actual throughput depends on your device. Speed and autosave choices are remembered.

Under the shell

Advanced EmulatorJS settings in Cartridges opens the native graphics, speed, capture settings and core options without restarting the game. Close it or press Escape to return. Choices are remembered on close; options marked Requires restart apply on the next power on. Key bindings, sound and checked save/backup handling remain in Cartridges. Opening settings does not pause gameplay.

Keep your place

Auto-save captures a rolling checkpoint every 15 seconds, including cartridge battery-save data when available. It can be disabled independently of manual checkpoints. Selecting the same ROM normally resumes the newest checkpoint across all slots, even if renamed. After a deliberate power off it boots from the in-game save instead, until a new checkpoint is captured. Three manual slots keep independent checkpoints; your original quick save is Slot 1. Save and load icons use the selected slot. Restore replaces progress since that save. Save before closing; abrupt shutdowns can lose the latest progress.

Take a backup

Export captures the current session, not the entire slot collection, to a .bba-save file. Select the matching ROM before importing. Imports replace the running session and selected manual slot, leaving other manual slots intact. Backups depend on the exact ROM bytes and EmulatorJS 4.2.3 / mGBA; they are not other emulators' .sav files.

Saves and the current cartridge belong to this browser profile and website origin. Cleared or evicted site data and private browsing can remove them. Export regularly. The current ROM is remembered locally when storage is available; nothing is uploaded.

Independent player, not affiliated with Nintendo. Internet is required for the pinned third-party runtime, which receives normal network metadata and executes with this site's privileges. No offline guarantee, accounts or cloud synchronization.

A SECOND CONSOLE. THE SAME TABLE.

BowserBOY DS

Local prototype / Nintendo DS direct boot / EmulatorJS 4.2.3 + DeSmuME. Not a replacement for the GBA.

Insert a DS cartridge or try the original Twin Lab demo.

Insert a DS game card

No DS cartridge inserted. Uncompressed .nds, up to 512 MB.

Or drop one .nds file onto the desk. Files remain on your device. No commercial games, BIOS or firmware are supplied.

DS progress / separate from GBA

One checkpoint per exact ROM, automatically saved every 30 seconds while playing. Choosing the same ROM resumes it. Power on after power off boots from in-game save data, not the checkpoint. ROM selection is not remembered across reloads.

Browser storage can be cleared or evicted. Export .bbds-save regularly. GBA .bba-save and raw .sav files are not DS checkpoint imports.

Two screens. A real touchscreen.

Pick up DS to play. Click, tap or drag on its lower physical LCD to use the stylus. The slim lime stylus is clipped to the shell; touch is sent from your pointer.

Arrows = D-pad / Z = A / X = B / C = X / V = Y / A = L / S = R / Enter = Start / left Shift = Select. Click the scene for keyboard focus. DS keys are fixed in this prototype; GBA remapping is unchanged.

Selecting the other console pauses this one. Single-threaded WebAssembly needs internet on first load, but no isolation headers or backend. DS games can be CPU-heavy; phone speed and commercial-game compatibility are not guaranteed. DSi, microphone, lid gestures, multiplayer and BIOS-menu boot are not implemented. Unsupported ROMs and runtime/download errors are reported here.
